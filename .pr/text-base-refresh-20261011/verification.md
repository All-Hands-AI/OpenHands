## Reproduce the live comparison

From each checkout, put `.agents/skills/verify-openhands/scripts` on PATH and use the bundled Node 24 runtime. Launch an independent run with `control-openhands launch --new`, run `doctor`, then `onboard --skip`. On this macOS machine the physical-free-memory guard required `--min-free-mb 0`; `memory_pressure -Q` reported 58% available and only one stack ran at a time.

At /settings/app select each named theme through `testid=color-theme-input`, then visit / and /automations/setup. Inspect computed backgrounds of `root-layout`, `automation-setup-panel`, and `automation-setup-topbar`, and the font size/line height of `chat-input`. Capture the neutral desktop views (1440x1000) and Light+ home at phone width (390x844). Stop the owned run.

These captures and measurements cover the named surfaces and fixed-size composer; they do not claim a pixel comparison of every route or a live Cloud/Electron/LLM interaction.
