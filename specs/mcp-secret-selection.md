# MCP credential selection

### MCP-005: Credential selection stays readable in every theme

- [x] The catalog's **Also save as secret** row follows the active palette,
      with readable labels and secret names in both checked and unchecked states.
- [x] The selected switch uses Canvas's shared toggle appearance; color alone
      does not communicate the checkbox state.
- [x] Long secret names and the help control remain inside the row on phones.
- [x] Label clicks and Space operate the native checkbox. Keyboard focus is
      visible, and opening help does not change the selection.
