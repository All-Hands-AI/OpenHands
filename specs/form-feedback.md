# Form feedback theme contract

### FF-001: Theme-aware validation and load errors
- [x] Form validation, profile load failures, missing-model guidance, and inline service errors shall use the host-overridable feedback-error text role. Invalid manifest control borders shall use semantic danger. Preserve messages, ARIA state, validation, retries, save behavior, and transport contracts; small error text must remain readable in all five themes.

### FF-002: Theme-aware connection status banners
- [x] Onboarding backend and ACP authentication banners shall use semantic status colors and readable feedback text roles across all five themes. A stored ACP credential shall remain visually neutral and distinct from a verified host login.
