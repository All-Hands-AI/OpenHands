# Settings switch contracts

### SSW-001: Settings switches expose native checkbox interaction

- [x] Enabled settings switches participate in Tab order and expose their
      label and checked state through the native checkbox accessibility role.
- [x] Space and label clicks toggle the same value. Keyboard focus is visible
      on the displayed control and label.
- [x] Disabled switches remain disabled, are skipped by Tab, and preserve their
      controlled checked state. Toggle position does not change these behaviors.
